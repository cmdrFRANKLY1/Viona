Netzwerkbefehle für Strolchfreunde

Grundlagen & Schnittstellen

Diese Befehle bilden das absolute Fundament. Sie helfen dir herauszufinden, wer du im Netzwerk bist und ob du grundlegend mit anderen kommunizieren kannst.

ping

Prüft die Erreichbarkeit eines Ziels mittels ICMP Echo-Requests.

Cross-Platform
Einfacher Test
ping 8.8.8.8
Dauerping (Windows) / Anzahl festlegen (Linux)
ping -t google.de # Windows (Abbruch mit Ctrl+C)
ping -c 4 google.de # Linux/Mac

Erweiterte Parameter (Windows)

-t : Fortlaufender Ping bis zum Abbruch
-a : Umgekehrte Namensauflösung der IP
-n [Zahl] : Anzahl der Echoanforderungen
-l [Byte] : Datenfeldlänge (max 65.527)
-f : "Nicht fragmentieren" setzen
-i [TTL] : Time-To-Live (max 255)
-v [TOS] : Type of Service (0-255)
-r [Anzahl] : Recordroute (zeichnet Pfad auf)
-s [Anzahl] : Internetzeitstempel (1-4)
-j [Liste] : Loose Source Route
-k [Liste] : Strict Source Route
-w [ms] : Timeout in Millisekunden

ipconfig / ip

Zeigt aktuelle IP-Konfiguration, Subnetzmaske und Gateway an. (Linux: ip addr)

Cross-Platform
Grundlegende Infos
ipconfig # Windows
ip a # Linux
DHCP & DNS erneuern/leeren (Windows)
ipconfig /release & ipconfig /renew
ipconfig /flushdns

Weitere Parameter (Windows)

/ALL : Alle Informationen (inkl. MAC)
/Batch [Datei] : Schreibt IP-Daten in Datei
/renew_all : Aktualisiert alle Adapter
/release_all : Gibt alle Adapter frei
/renew N : Adapter N aktualisieren
/release N : Adapter N freigeben

Routing, Wege & Namen

Diese Tools zeigen dir den Weg, den ein Paket nimmt, oder übersetzen die Namen des Internets in greifbare IP- und Hardwareadressen.

tracert / traceroute

Verfolgt den genauen Pfad (die einzelnen Router/Hops), den ein Paket zum Ziel nimmt.

Cross-Platform
Pfad anzeigen
tracert google.de # Windows
traceroute google.de # Linux

Erweiterte Parameter (Windows)

-d : Verhindert das Auflösen von IP-Adressen der Zwischenrouter in Namen (geht schneller)
-h [Hops] : Maximale Anzahl der Hops im Pfad
-j [Hostliste] : Nutzt Loose Source Route für die Liste der Zwischenziele
-w [ms] : Wartezeit in Millisekunden auf ICMP-Zeitüberschreitung

nslookup / dig

Fragt DNS-Server ab, um Domänennamen in IP-Adressen zu übersetzen (oder umgekehrt).

Cross-Platform
Standard Abfrage
nslookup heise.de
Spezifischen DNS-Server nutzen
nslookup heise.de 8.8.8.8
Linux Alternative (Sehr detailliert)
dig heise.de +short

arp / ip neigh

Zeigt den ARP-Cache, der IP-Adressen zu Hardware-MAC-Adressen im lokalen Netz zuordnet.

Cross-Platform
ARP-Tabelle anzeigen
arp -a # Windows / Mac
ip neigh # Linux

Spezifische Parameter

-a / -g : Zeigt die aktuellen ARP-Cachetabellen für alle Schnittstellen an
-s IP Mac [Schnittst.] : Fügt einen statischen Eintrag in den ARP-Cache ein
-d IP [Schnittst.] : Löscht den Eintrag dieser IP (Platzhalter * löscht alle)
Achtung: ARP funktioniert nur im lokalen Netzwerk (Layer 2). Du wirst hier niemals die MAC-Adresse eines Google-Servers sehen, sondern höchstens die deines Routers.

route print / ip route

Gibt die interne Routing-Tabelle deines PCs aus (wohin schickt er welche Pakete?).

Cross-Platform
Tabelle anzeigen
route print # Windows
ip route # Linux
Der wichtigste Eintrag ist meist "0.0.0.0" (bzw. "default") – das ist dein Standardgateway (meist dein Router), an das alles geschickt wird, was dein PC nicht direkt kennt.

Port- & Verbindungsanalyse

Wer kommuniziert gerade mit wem? Welche Türen (Ports) sind an deinem System offen? Diese Werkzeuge schauen tief unter die Haube.

netstat / ss

Zeigt alle aktiven TCP/UDP-Verbindungen sowie lauschende Ports und Statistiken an.

Cross-Platform
Die "Zeig mir alles"-Kombi (Windows)
netstat -ano
a = alle, n = Nummern statt Namen, o = Prozess-ID (PID)

Erweiterte Parameter

-a : Alle aktiven TCP- & UDP-Verbindungen / Ports
-e : Zeigt Ethernet-Statistiken (Pakete, Bytes) an
-n : Zeigt Adressen & Ports rein numerisch an
-o : Gibt die zugehörige Prozess-ID (PID) aus
-p [Protokoll] : Filtert nach (tcp, udp, tcpv6, udpv6)
-s : Zeigt Statistiken nach Protokollen
-r : Zeigt den Inhalt der IP-Routingtabelle

Port-Checks (tnc / nc)

Prüft, ob eine Firewall einen bestimmten Port blockiert.

Cross-Platform
Powershell (Windows)
Test-NetConnection 192.168.1.10 -Port 80
Netcat (Linux / Mac)
nc -vz 192.168.1.10 80

curl

Sendet Netzwerkanfragen (meist HTTP/HTTPS) über die Kommandozeile.

Cross-Platform
Webseite abrufen & Header sehen
curl -I https://google.de

ssh

Baut eine sichere, verschlüsselte Konsolen-Verbindung zu einem entfernten System auf.

Cross-Platform
Mit Server verbinden
ssh benutzername@192.168.1.50

telnet

Baut eine zeilengestützte Terminal-Kommunikation mit einem Remotecomputer (Telnet-Server) auf.

Windows

Durch das Zusammenwirken von Telnet-Client und Telnet-Server wird Benutzern die Kommunikation mit einem Remotecomputer ermöglicht. Mit dem Telnet-Client können Benutzer eine Verbindung aufbauen und über ein Terminalfenster einen Datenaustausch im Zeichenmodus durchführen.

Hinweis: Telnet-Server fungiert dabei als Gateway. Der Server, der zum Lieferumfang von Windows (z.B. XP) gehört, unterstützt oft maximal zwei Telnet-Clients gleichzeitig. Für mehr Lizenzen sind "Windows-Dienste für UNIX" erforderlich.

binary : Binär-Modus einstellen
bye / quit : FTP-Sitzung beenden
cd : Remote Arbeitsverzeichnis wechseln
cdup : Remote in Elternverzeichnis
chmod : Rechte an Remote-Datei ändern
close / disconnect : Verbindung trennen
cr : Umschaltung
debug : Debugger-Modus setzen

dir / ls : Verzeichnisinhalt anzeigen
form : FTP-Format setzen
get / recv : Datei empfangen
glob : glob aus/an
hash : Parameter für Geschw.-Anzeige
idle : Idle Zeitlimit (900-7200s)
lcd : Lokales Verzeichnis wechseln
macdef : Makro definieren
mdelete : Mehrere Dateien löschen
mdir / mls : Inhalt mehrerer Remote-Verz.
mget : Mehrere Dateien empfangen
mkdir : Remote-Verzeichnis erstellen
mode : FTP-Modus setzen
modtime : Änderungszeit von Datei
mput : Mehrere Dateien senden
newer : Empfang, wenn Datei neuer
nlist : Inhalt von Remote-Verzeichnissen
open : Verbindung aufbauen
prompt : Interaktiver Prompt erzwingen
put / send : Datei senden
pwd : Arbeitsverzeichnis anzeigen
rename : Dateiname ändern
restart : Neustart Übertragung
rhelp : Hilfe vom Remote Server anfordern
rmdir : Remote Verzeichnis entfernen
rstatus : Status der Remote-Maschine
size : Dateigröße von Remote-Datei
status : Aktuellen Status anzeigen
struct : FTP-Struktur setzen
system : Remote-Systemtyp anzeigen
tenex : Tenex Datei-Typ setzen
trace : Paketverfolgung (an/aus)
type : FTP-Typ setzen
user : Neue User-Info senden
verbose : Umschalten auf Verbose Modus

net

Umfangreiches Netzwerk-Programm mit vielen Unterfunktionen (z.B. Freigaben, Konten). Nutze net /? für alle Details.

Windows
Befehl Beschreibung & Spezifische Parameter
net accounts Aktualisiert die Benutzerkontendatenbank (Der Anmeldedienst muss ausgeführt werden).
/forcelogoff:{Minuten|no}Trennt Session bei Ablauf von Anmeldezeit. /minpwlen:LängeMinimale Kennwortlänge. /maxpwage:{Tage|unlimited}Maximale Gültigkeitsdauer des Kennworts. /minpwage:TageFrühester Zeitpunkt für Kennwortänderung. /uniquepw:AnzahlZähler, bevor Kennwort wiederholt werden darf. /domainFührt Aktion auf dem primären Domänencontroller aus.
net config Zeigt konfigurierbare Dienste an oder ändert Einstellungen.
Syntax: net config [{server|workstation}]
net file Zeigt geöffnete/freigegebene Dateien auf einem Server (Kann Freigabe schließen).
Syntax: net file [ID [/close]]
net help Gibt ausführliche Hilfe zu net-Befehlen aus. (net help [Befehl])
net share Zeigt und verwaltet freigegebene Ressourcen (Ohne Parameter = Liste lokaler Freigaben).
net use Verbindet oder trennt Computer von einer Freigabe (Ohne Parameter = Liste aktiver Verbindungen).
net view Zeigt eine Liste der Domänen, Computer oder freigegebenen Ressourcen an.
[ohne Parameter]Computer in aktueller Domäne. \\ComputernameRessourcen eines spezifischen Computers anzeigen. /allZeigt alle Freigaben an. /domain[:Domänenname]Computer der ausgewählten (oder aller) Domänen.
