1. Klasse, Objekt und Instanziierung

Klasse
Abstraktes Schema, das Attribute und Methoden gleichartiger Objekte definiert.
Objekt
Konkrete Instanz einer Klasse mit eigener Identität, eigenem Zustand und Verhalten.
Instanziierung
Erzeugung eines Objekts nach dem Bauplan einer Klasse, häufig durch einen Konstruktor.
Konstruktor
Spezielle Operation, die beim Erzeugen eines Objekts dessen Anfangszustand herstellt.

2. Die vier Grundprinzipien

Abstraktion
Reduktion auf die für den Zweck wesentlichen Merkmale. Ein Kundenobjekt braucht eine Kundennummer, aber keine Augenfarbe.
Kapselung
Interner Zustand wird verborgen und nur über definierte Methoden kontrolliert gelesen oder verändert.
Vererbung
Eine spezialisierte Unterklasse übernimmt Merkmale einer allgemeineren Oberklasse und kann sie ergänzen oder überschreiben.
Polymorphismus
Objekte verschiedener Unterklassen werden über dieselbe Schnittstelle angesprochen, führen den Aufruf aber typspezifisch aus.

3. Kapselung in Code

class Konto {
        #saldo = 0;
        einzahlen(betrag) {
                if (betrag <= 0) throw new Error('Betrag muss positiv sein');
                this.#saldo += betrag;
        }
        getSaldo() { return this.#saldo; }
}

Die Methode kontrolliert die Zustandsänderung. Ein beliebiger ungültiger Wert kann nicht direkt in saldo geschrieben werden.

VorteilKonkrete WirkungMöglicher Nachteil
WiederverwendbarkeitGemeinsamer Code muss nicht mehrfach implementiert werden.Unpassende Vererbung erzeugt starre Abhängigkeiten.
WartbarkeitÄnderungen bleiben durch Kapselung lokal.Viele Klassen erhöhen anfangs die Komplexität.
ErweiterbarkeitNeue Unterklassen nutzen bestehende Schnittstellen.Abstraktionen verursachen Entwurfsaufwand.
TestbarkeitKlassen können isoliert geprüft werden.Abhängigkeiten benötigen Test-Doubles.

Häufige Verwechslungen

  • Ein Objekt ist keine Unterklasse, sondern eine Instanz.
  • Vererbung ist „ist-ein“; Zusammensetzung ist „hat-ein“.
  • Überladen: gleicher Name, andere Parameterliste. Überschreiben: neue Implementierung einer geerbten Methode.
  • Ein Schlagwort ohne Wirkung reicht bei „erläutern“ oder „begründen“ nicht.

4. Übungen

Stufe 1

Welches Prinzip schützt Attribute vor unkontrolliertem Zugriff?

Kapselung verbirgt den Zustand hinter einer Schnittstelle.
Stufe 2

Nenne zwei Vorteile und erläutere ihre Wirkung.

Wiederverwendbarkeit reduziert doppelten Code; Wartbarkeit begrenzt Änderungsauswirkungen.
Stufe 3

Ein System modelliert Elektroauto als Unterklasse von Motor. Beurteile den Entwurf und schlage eine korrekte Beziehung vor.

Falsch: Ein Elektroauto ist kein Motor, sondern hat einen Motor. Motor wird über Aggregation oder Komposition verbunden; Elektroauto kann Unterklasse von Fahrzeug sein.

  • Klasse und Objekt sicher unterscheiden.
  • Jedes Grundprinzip mit Wirkung erklären.
  • Bei Vererbung die „ist-ein“-Probe anwenden.
  • Vor- und Nachteile konkret begründen.
