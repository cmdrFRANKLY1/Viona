2. SELECT vollständig verstehen

SELECT ort, COUNT(*) AS anzahl
FROM kunde
WHERE aktiv = TRUE
GROUP BY ort
HAVING COUNT(*) >= 3
ORDER BY anzahl DESC;

3. JOINs als Ergebnismengen

SELECT k.name, b.bestellung_id
FROM kunde AS k
LEFT JOIN bestellung AS b
  ON b.kunden_id = k.kunden_id;

Ein LEFT JOIN zeigt auch Kunden ohne Bestellung; deren Bestellspalten enthalten NULL. Ein CROSS JOIN bildet jedes Paar. Ein Self Join verbindet eine Tabelle mit sich selbst, etwa Mitarbeiter mit Vorgesetzten.

4. NULL ist kein Wert

SELECT name, COALESCE(email, 'keine E-Mail') AS kontakt
FROM kunde
WHERE email IS NULL;

= NULL ist falsch. NULL bedeutet unbekannt beziehungsweise nicht vorhanden und wird mit IS NULL oder IS NOT NULL geprüft.

5. Unterabfragen und Mengen

SELECT name
FROM kunde
WHERE kunden_id IN (
  SELECT kunden_id FROM bestellung WHERE gesamtwert > 1000
);

IN prüft eine Wertemenge, EXISTS das Vorhandensein mindestens einer Zeile. UNION kombiniert kompatible Ergebnismengen und entfernt Duplikate; UNION ALL behält sie.

6. Daten sicher ändern

BEGIN;
UPDATE kunde SET ort = 'Bonn' WHERE kunden_id = 18;
-- Ergebnis prüfen
COMMIT;  -- oder ROLLBACK
UPDATE und DELETE zuerst als SELECT mit identischer WHERE-Bedingung prüfen. In Transaktionen kann ein Fehler vor COMMIT zurückgerollt werden.

Häufige Fehler

  • WHERE COUNT(*) statt HAVING COUNT(*).
  • Nicht aggregierte SELECT-Spalten fehlen in GROUP BY.
  • JOIN ohne passende ON-Bedingung erzeugt ein kartesisches Produkt.
  • = NULL statt IS NULL.
  • UPDATE oder DELETE ohne WHERE verändert alle Zeilen.
  • LEFT JOIN wird durch einen Filter auf die rechte Tabelle in WHERE unbeabsichtigt wie INNER JOIN.

Stufe 1

SELECT * FROM kunde WHERE ort = 'Köln';

Welche Klausel filtert Gruppen?

HAVING filtert Gruppen.
Stufe 2

Gib alle Kunden aus, auch solche ohne Bestellung, und zeige die Anzahl ihrer Bestellungen.

SELECT k.kunden_id, k.name, COUNT(b.bestellung_id) AS anzahl
FROM kunde k
LEFT JOIN bestellung b ON b.kunden_id = k.kunden_id
GROUP BY k.kunden_id, k.name;

COUNT(b.bestellung_id) ergibt für fehlende Treffer 0; COUNT(*) würde die erhaltene Kundenzeile zählen.

Stufe 3

Liste Kundenname und Bestellgesamtwert für aktive Kunden mit mehr als drei Bestellungen. Zeige nur Summen über 1.000 Euro, absteigend sortiert.

SELECT k.name, SUM(b.gesamtwert) AS umsatz
FROM kunde k
JOIN bestellung b ON b.kunden_id = k.kunden_id
WHERE k.aktiv = TRUE
GROUP BY k.kunden_id, k.name
HAVING COUNT(*) > 3 AND SUM(b.gesamtwert) > 1000
ORDER BY umsatz DESC;
  • Zuerst benötigte Ergebnisspalten und Tabellen bestimmen.
  • JOIN-Bedingung aus PK/FK ableiten.
  • Zeilenfilter in WHERE, Gruppenfilter in HAVING.
  • NULL mit IS NULL behandeln.
  • Änderungen transaktional und mit enger WHERE-Klausel ausführen.

5. IHK-Training

Geben Sie Name und Bestellanzahl aller Kunden mit mindestens zwei Bestellungen aus. Sortieren Sie absteigend.

SELECT k.name, COUNT(b.bestellung_id) AS anzahl
FROM kunde AS k
JOIN bestellung AS b ON b.kunden_id = k.kunden_id
GROUP BY k.kunden_id, k.name
HAVING COUNT(b.bestellung_id) >= 2
ORDER BY anzahl DESC;
