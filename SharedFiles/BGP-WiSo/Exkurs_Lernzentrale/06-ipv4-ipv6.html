1. Vergleich ohne ungenaue Aussagen

MerkmalIPv4IPv6
Länge32 Bit128 Bit
Notation4 dezimale Oktette8 hexadezimale 16-Bit-Blöcke
Adressraum2322128
Broadcastvorhandenkein Broadcast; Multicast/Anycast
Konfigurationstatisch oder DHCPSLAAC, DHCPv6 oder statisch
NachbarschaftARPNeighbor Discovery über ICMPv6
IPv6 ist nicht pauschal „schneller“ oder „stabiler“. Prüfungssicher sind konkrete Unterschiede wie Bitlänge, Adressraum, Notation, Header und Konfiguration.

2. Wichtige Adressbereiche

BereichZweck

127.0.0.0/8IPv4-Loopback, meist 127.0.0.1.

Unicast adressiert eine Schnittstelle, Multicast eine Empfängergruppe und Anycast mehrere Schnittstellen, von denen das Routing eine nahe auswählt.

3. IPv6 korrekt kürzen

2001:0db8:0000:0000:00a0:0000:0000:0001

  1. Führende Nullen je Block entfernen: 2001:db8:0:0:a0:0:0:1.
  2. Eine zusammenhängende Nullblockfolge einmal durch :: ersetzen.
  3. Eine gültige Kurzform ist 2001:db8::a0:0:0:1.
  4. :: darf nur einmal vorkommen, sonst wäre die Anzahl ausgelassener Blöcke nicht eindeutig.

4. IPv6-Konfiguration

Bei SLAAC kündigt ein Router per Router Advertisement das Präfix an; der Host bildet seine Adresse selbst. DHCPv6 kann weitere Parameter und bei Stateful DHCPv6 auch Adressen vergeben. Die Link-Local-Adresse entsteht unabhängig davon automatisch und ist für Neighbor Discovery wichtig.

5. Übergangsverfahren

Dual Stack

Beide Protokollstapel laufen parallel. Einfach zu verstehen, aber beide Netze müssen betrieben und abgesichert werden.

Tunneling

IPv6-Pakete werden in IPv4 eingekapselt, wenn dazwischen nur IPv4-Infrastruktur besteht.

Translation

NAT64 übersetzt zwischen IPv6- und IPv4-Kommunikation; DNS64 kann passende synthetische AAAA-Antworten erzeugen.

Präferenz

Moderne Clients probieren geeignete Ziele intelligent; ein bloßer AAAA-Record garantiert keine funktionierende IPv6-Verbindung.

Häufige Fehler

  • 2001:db8::1::5 ist ungültig, weil :: zweimal vorkommt.
  • Link-Local wird mit öffentlich routbar verwechselt.
  • Private IPv4-Adressen werden als grundsätzlich unerreichbar bezeichnet statt als öffentlich nicht direkt routbar.
  • Dual Stack wird mit Tunneling gleichgesetzt.

Stufe 3

Ein IPv6-only-Client muss einen alten IPv4-only-Dienst erreichen. Welches Verfahren ist geeignet und welche Komponenten werden benötigt?

NAT64 übersetzt die Pakete; DNS64 kann aus einem A-Record eine für den Client nutzbare synthetische AAAA-Antwort bilden. Dual Stack allein hilft einem tatsächlich IPv6-only-Client nicht.
